AI Browser HUD Assistant for Windows 10/11 (v2.3 gemini-3.6-flash, Audio Capture, Pure Code)
================================================================================
Фоновый анализ активного окна браузера и/или входящего звука собеседника (Zoom / Яндекс Телемост / Teams)
с помощью Gemini 3.6 Flash без потери фокуса ввода.
Снимок из памяти через Win32 API + Аудиозахват динамиков собеседника + Прозрачный Click-Through HUD (PyQt6).

ВОЗМОЖНОСТИ:
• Исключительно модель 'gemini-3.6-flash' 
• Задачи по кодингу: ТОЛЬКО чистый код на Python 3, без комментариев, без вступительных
  слов, пояснений и лишних пустых строк/отступов.
• АУДИОЗАХВАТ ГОЛОСА СОБЕСЕДНИКА (Zoom / Яндекс Телемост / Teams):
  - CTRL + ALT + Q — первое нажатие включает запись входящего голоса собеседника из динамиков/наушников (WASAPI Loopback),
    второе нажатие — останавливает запись и мгновенно отправляет аудио в Gemini 3.6 Flash.
    В оверлей выводится точный, четкий ответ без воды!
• ГЛОБАЛЬНЫЕ ХОТКЕИ (сочетания через CTRL + ALT):
  - CTRL + ALT + S — мгновенный снимок и анализ активного окна браузера
  - CTRL + ALT + Q — старт/стоп прослушки собеседника и анализ голоса
  - CTRL + ALT + C — скрыть оверлей (ответ сохраняется в памяти)
  - CTRL + ALT + D — вернуть оверлей с предыдущим ответом
  - CTRL + ALT + Z — прокрутить ответ ВВЕРХ
  - CTRL + ALT + X — прокрутить ответ ВНИЗ
• Защита от захвата экрана:
  - Окно НЕВИДИМО в Zoom, Яндекс Телемост, Teams, Discord, OBS (SetWindowDisplayAffinity 0x11).

--------------------------------------------------------------------------------

================================================================================
